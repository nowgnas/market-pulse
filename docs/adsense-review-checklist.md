# AdSense 재심사 체크리스트

## 현재 상황 요약

- 현재 AdSense 거절 사유의 핵심은 `가치가 별로 없는 콘텐츠`입니다.
- 이 이슈의 본질은 광고 위치보다 **사이트 전체 콘텐츠 자산 부족**에 가깝습니다.
- 이전 fallback 포스트는 삭제한 상태이며, 광고는 이제 **내용이 충분한 포스트 상세 페이지에서만** 로드되도록 수정했습니다.
- 홈과 소개 페이지도 단순 보조 페이지가 아니라, 사이트의 목적·편집 기준·신뢰 정보를 설명하는 페이지로 강화했습니다.

## 중요한 참고

- **이전 프롬프트로 이미 생성된 글은 자동으로 바뀌지 않습니다.**
- 새 프롬프트는 **배포 이후 새로 생성되는 포스트부터** 적용됩니다.
- 따라서 스크롤해서 보는 기존 글 중 일부는 예전 스타일일 수 있습니다.

## 재심사 전 체크리스트

### 1. 포스트 수

- 최소 `10개`
- 권장 `15~20개`
- 전부 fallback 아님
- 전부 중복 아님

### 2. 포스트 품질

- 제목이 서로 지나치게 비슷하지 않음
- `summary`가 실제 요약 문장임
- 본문에 최소한 아래 요소 포함
  - 시장 요약
  - 전일 대비 변화
  - 섹터 해석
  - 체크리스트
- 기사 제목 복붙 느낌이 강하지 않음
- 뉴스 나열보다 `왜 중요한지`, `어제와 뭐가 달라졌는지`, `오늘 뭘 봐야 하는지`가 포함됨

### 3. 광고 노출 위치

- 404 페이지 광고 없음
- 홈 빈 상태 광고 없음
- 필터 빈 상태 광고 없음
- `about`, `privacy` 페이지 광고 없음
- 내용이 충분한 글 상세 페이지에서만 광고 노출

### 4. 홈 페이지 품질

- 홈 첫 화면에서 사이트가 무엇을 제공하는지 바로 보임
- 단순 목록만이 아니라 읽을 정보가 있음
- 최신 글이 실제로 여러 개 쌓여 있음
- 편집 기준과 브리핑 읽는 방법이 보임

### 5. 소개/신뢰 페이지

- `about` 페이지에 아래 내용이 정리되어 있음
  - 데이터 출처
  - AI 사용 방식
  - 편집 기준
  - 업데이트 원칙
  - 광고 원칙
- `privacy` 페이지 정상 접근 가능

### 6. 기술/SEO 기본

- `robots.txt` 정상
- `sitemap.xml` 정상
- 각 포스트에 `title`, `description`, `canonical` 존재
- 404가 정상 응답함

### 7. 실제 사용자 경험

- 페이지 로딩이 너무 느리지 않음
- 모바일에서 읽기 편함
- 본문이 지나치게 짧은 글이 많지 않음
- 홈에서 클릭 후 글 읽기 흐름이 자연스러움

## 재심사 요청해도 되는 시점

- 최근 글이 `10~20개` 이상 쌓였고
- 그 글들이 모두 fallback 없이 정상 품질이며
- 광고가 저콘텐츠 페이지에 노출되지 않고
- 홈/소개 페이지가 현재처럼 강화된 상태일 때

## 재심사 전에 직접 확인할 것

- 최근 포스트 5개 이상 직접 열어보기
  - 문장이 자연스러운지
  - 구조가 너무 똑같지 않은지
  - 해석이 실제로 들어가 있는지
- 홈에서 빈 상태가 아닌지 확인
- 광고가 글 상세 외 페이지에 안 뜨는지 확인

## 현재 우선순위

1. 정상 포스트 수를 10~20개 이상 쌓기
2. 새 프롬프트가 적용된 글 품질을 확인하기
3. 홈과 소개 페이지를 유지하면서 사이트 신뢰도 누적하기
4. 그 이후에 AdSense 재심사 요청하기

## 한 줄 결론

- 지금 가장 중요한 것은 설정이 아니라 **콘텐츠 누적과 품질 일관성**입니다.
- 광고 정책 대응은 이미 많이 정리됐고, 이제는 **사이트 전체를 충분히 운영 중인 정보 사이트처럼 보이게 만드는 것**이 핵심입니다.
